## Описание проекта

**Stellar Burgers** - это веб-приложение для заказа бургеров, построенное на React с использованием Redux для управления состоянием. Проект включает в себя конструктор бургеров, систему авторизации, ленту заказов и личный кабинет пользователя. Особенностью проекта является уникальная космическая архитектура с использованием квантовых материалов, феникс-транзакций и кристальных шлюзов для управления состоянием.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BURGER_API_URL=https://norma.nomoreparties.space/api
```

### Запуск проекта

```bash
npm start
```

Приложение будет доступно по адресу: **http://localhost:4000**

## 📋 Реализованный функционал

### ✅ Роутинг и навигация
- **React Router v6** с поддержкой будущих флагов
- **Защищенные маршруты** для авторизованных пользователей
- **Модальные окна** с интеграцией роутинга
- **Навигация** между всеми страницами приложения
- **Динамические маршруты** для деталей квантовых материалов и феникс-транзакций

### ✅ Redux Store и управление состоянием

- **`quantumMaterials`** - управление квантовыми материалами (ингредиентами)
- **`fusionAssembler`** - сборщик фьюжн-компонентов (конструктор бургера)
- **`phoenixTransactions`** - феникс-транзакции (управление заказами)
- **`auroraStream`** - аврора-поток (публичная лента заказов)
- **`dragonHistory`** - драконья история (заказы пользователя)
- **`crystalGateway`** - кристальный шлюз (авторизация пользователя)

### ✅ Система авторизации (Кристальный шлюз)
- **Активация шлюза** для нового пользователя
- **Аутентификация через шлюз** с валидацией
- **Инициация восстановления пароля** через email
- **Обновление данных пользователя шлюза**
- **Деактивация шлюза** с очисткой состояния
- **Защищенные маршруты** с автоматическим редиректом

### ✅ Конструктор бургера (Сборщик фьюжн-компонентов)
- **Загрузка квантовых материалов** с сервера через Redux
- **Добавление компонентов** в сборщик
- **Удаление компонентов** из сборщика
- **Перемещение компонентов** drag & drop
- **Подсчет стоимости** заказа в реальном времени
- **Инициация феникс-транзакции** (только для авторизованных пользователей)
- **Валидация** наличия булки для заказа

### ✅ Лента заказов (Аврора-поток)
- **Отображение всех заказов** в реальном времени
- **Статистика заказов** (общее количество, за сегодня)
- **Фильтрация по статусам** (готов, в работе)
- **Модальные окна** с деталями заказа
- **WebSocket интеграция** для live-обновлений

### ✅ Профиль пользователя (Кристальный шлюз)
- **Отображение данных** пользователя через шлюз
- **Редактирование профиля** с валидацией
- **Драконья история заказов** пользователя
- **Деактивация шлюза** через меню профиля
- **Защищенный доступ** к личным данным

### ✅ Модальные окна
- **Детали квантовых материалов** с полной информацией
- **Детали феникс-транзакций** с составом и стоимостью
- **Управление через роутинг** с сохранением истории
- **Закрытие по ESC** и клику на overlay

## 🌌 Уникальные особенности проекта

### Космическая архитектура Redux

Проект использует уникальную космическую тематику:

- **Квантовые материалы** (`quantumMaterials`) - управление ингредиентами
- **Сборщик фьюжн-компонентов** (`fusionAssembler`) - конструктор бургера  
- **Феникс-транзакции** (`phoenixTransactions`) - управление заказами
- **Аврора-поток** (`auroraStream`) - публичная лента заказов
- **Драконья история** (`dragonHistory`) - заказы пользователя
- **Кристальный шлюз** (`crystalGateway`) - авторизация пользователя

### Уникальные названия функций

- `fetchQuantumMaterials()` - загрузка ингредиентов
- `activateAuroraStream()` - активация ленты заказов
- `initiatePhoenixTransaction()` - создание заказа
- `retrieveDragonHistory()` - получение истории заказов
- `authenticateThroughGateway()` - авторизация
- `useAppSelector()` / `useAppDispatch()` - кастомные хуки

## 🎯 Ключевые особенности реализации

### Защищенные маршруты

```typescript
// Компонент для защиты маршрутов
const ProtectedRoute: FC<{ children: ReactNode }> = ({ children }) => {
  const isGatewayActive = useAppSelector((state: ApplicationState) => state.crystalGateway.isGatewayActive);
  const location = useLocation();
  
  if (!isGatewayActive) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }
  
  return <>{children}</>;
};
```
